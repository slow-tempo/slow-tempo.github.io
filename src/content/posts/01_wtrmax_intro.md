## 1. wtrmax는 무엇인가

wtrmax는 작은 데스크톱 컴퓨터이다.

흔히 미니 PC라고 부르는 크기이며, 집에서 24시간 켜두고 서버로 쓰기 위해 만든 기계이다.

![wtrmax 공식 제품 이미지](/images/wtrmax-official.jpg)

이미지 출처: [AOOSTAR 공식 제품 페이지](https://aoostar.com/products/aoostar-wtr-max-amd-r7-pro-8845hs-11-bays-mini-pc)

이 시리즈에서는 이 기계가 home nas의 몸통 하드웨어가 된다. 파일이 실제로 저장되고 서비스가 돌아가는 호스트이다.

## 2. 서버용으로 적합한 이유

집에서 쓰는 큰 데스크톱도 서버가 될 수는 있다.

하지만 데스크톱은 게임이나 작업을 위해 켜는 기계라서, 항상 켜두기에는 전기와 소음, 공간이 부담이 된다.

wtrmax 같은 작은 서버용 기계는 그 반대로 설계되어 있다.

```text
작은 크기 → 책상 한쪽이나 선반에 두고 쓴다
24시간 동작 전제 → 항상 켜두는 서버로 쓴다
소음 → 냉각 구조가 조용하게 설계되어 있다
전성비 → 모바일 계열 프로세서를 써서 전력 대비 성능이 좋다
여러 저장장치 → 파일 저장소로 쓴다
```

즉, 항상 켜져 있고 파일을 맡아두는 집 서버라는 역할에 맞는 하드웨어이다.

## 3. 저장장치 수

wtrmax의 베이 수는 다음과 같다.

```text
SATA 3.5인치 베이 6개
M.2 NVMe 슬롯 5개 (PCIe 4.0 x2 3개 + PCIe 4.0 x1 2개)
합계 11개
```

이 시리즈에서 저장 풀로 쓰는 장치는 하드디스크 6개와 NVMe 2개이다. 시스템용 NVMe 1개는 별도이다.

## 4. 간단 스펙 요약

### 4-1. 내 구성 (실측)

```text
CPU: AMD Ryzen 7 PRO 8845HS (8코어/16스레드)
그래픽: Radeon 780M 내장
메모리: DDR5 5600 32GB x 2개 = 64GB (ECC 아님)
저장: 하드디스크 6개 (저장 풀) + NVMe 2개 (저장 풀) + NVMe 1개 (시스템용)
이더넷: 10Gb SFP+ 2개 + 2.5Gb RJ45 2개
```

### 4-2. 공식 스펙

```text
CPU: AMD Ryzen 7 PRO 8845HS
그래픽: Radeon 780M 내장
메모리: DDR5 5600 슬롯 2개, 최대 128GB, ECC 지원
저장 베이: SATA 3.5인치 6개 + M.2 NVMe 슬롯 5개 (PCIe 4.0 x2 3개 + PCIe 4.0 x1 2개), 합계 11개
메인보드 슬롯 1개도 PCIe 4.0 x2이다.
이더넷: 10Gb SFP+ 2개 + 2.5Gb RJ45 2개
영상: HDMI 2.1 1개 + DP 1.4 1개
USB: USB 3.2 Gen 2 2개 + USB 3.2 Gen 1 1개 + USB4 1개
확장: OCuLink 1개
기타: 2-in-1 오디오 1개 + microSD 슬롯 1개 + DC 전원 1개
```

### 4-3. 기본 구성품과 아닌 것

기본 구성품은 다음과 같다.

```text
본체 1개
HD 케이블 1개
전원 1개
설명서 1개
```

기본 구성품이 아닌 것은 다음과 같다. 베어본 기준이다.

```text
RAM
SSD
하드디스크
```

이 시리즈의 기계는 RAM 64GB와 저장장치를 별도로 장착한 구성이다.

## 5. wtrmax에서 돌아가는 것

이 시리즈에서는 wtrmax 위에 Proxmox를 올린다.

Proxmox는 한 기계 안에 여러 대의 작은 서버를 나눠서 돌리는 가상화 소프트웨어이다.

wtrmax 안에서 돌아가는 것은 다음과 같다.

```text
wtrmax
    │
    ├────── 파일 저장소 (ZFS 풀)
    ├────── Nextcloud (웹으로 파일 보기)
    ├────── Samba (윈도우에서 폴더처럼 연결)
    └────── 프록시 (밖에서 접속할 때 문지기)
```

하드웨어는 하나지만, 안에서는 역할별로 나뉜 여러 서비스가 돌아간다.
