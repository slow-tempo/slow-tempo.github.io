## 1. Proxmox

Proxmox는 가상화 소프트웨어이다.

한 기계 안에 여러 대의 작은 서버를 나눠서 돌리는 역할을 한다. 이 작은 서버를 컨테이너나 가상 머신이라고 부른다.

이 시리즈에서는 wtrmax 위에 Proxmox를 올린다. Proxmox 위에서 파일 저장소, Nextcloud, Samba, 프록시를 나눠서 돌린다.

## 2. Proxmox 설치

Proxmox는 ISO 파일로 설치한다. 공식 사이트에서 Proxmox VE ISO를 받아서 USB에 굽는다.

USB로 기계를 부팅한다. 기계가 USB가 아니라 하드디스크로 부팅되면, 부팅 메뉴에서 USB를 고른다. 부팅 메뉴는 전원을 켤 때 특정 키를 눌러서 연다.

Install Proxmox VE를 고른다. 설치할 디스크를 고를 때는 조심한다. 고른 디스크에 있는 내용은 전부 지워진다. 다른 디스크를 고르면 그 디스크가 지워진다.

root 비밀번호와 관리용 네트워크 주소를 정한다. 관리용 네트워크 주소는 IP 주소, 넷마스크, 게이트웨이를 적는다. IP 주소는 `192.168.0.100/24` 같은 형태이다. 호스트 이름과 시간대도 정한다.

설치가 끝나면 기계를 재부팅한다. 브라우저에서 관리 주소로 접속한다. 주소는 `https://관리IP:8006` 형태이다. root 계정으로 로그인한다. 유료 구독이 없다는 안내가 뜨는데, 무료로 쓸 때는 그대로 두면 된다.

## 3. 가상화

가상화는 한 대의 물리 기계를 여러 대의 논리 기계처럼 쓰는 방법이다.

가상화를 쓰지 않으면, 서비스마다 기계를 따로 두어야 한다. 가상화를 쓰면, 기계 한 대에 서비스를 여러 개 올려도 서로 간섭하지 않는다.

```text
가상화 없음
    │
    ├──── 기계 1: Nextcloud
    ├──── 기계 2: Samba
    └──── 기계 3: 프록시

가상화 사용
    │
    └──── 기계 1 (Proxmox)
             ├──── Nextcloud
             ├──── Samba
             └──── 프록시
```

## 4. 컨테이너와 가상 머신

Proxmox에서는 컨테이너와 가상 머신을 둘 다 쓸 수 있다.

컨테이너는 호스트의 커널을 공유해서 가볍게 돌리는 방법이다. 시작이 빠르고 자원을 적게 쓴다.

가상 머신은 운영체제까지 통째로 가상화하는 방법이다. 컨테이너보다 무겁지만, 호스트와 완전히 분리된다.

이 시리즈에서는 가벼운 서비스는 컨테이너로 돌린다. Nextcloud, Samba, 프록시는 모두 컨테이너이다.

## 5. 서비스를 나누는 이유

서비스를 나누면, 한 서비스에 문제가 생겨도 다른 서비스는 그대로 돈다.

예를 들어 프록시에 문제가 생겨도, Nextcloud와 Samba는 영향을 받지 않는다. 반대로 Nextcloud를 고치는 동안에도, Samba로 파일을 쓰는 일은 계속된다.

서비스마다 자원을 따로 정할 수도 있다. 한 서비스가 자원을 다 써서 다른 서비스를 멈추게 하는 일을 막는다.

## 6. Proxmox 관리

Proxmox는 웹 화면으로 관리한다.

컨테이너를 만들고, 시작하고, 멈추는 일을 웹 화면에서 한다. 각 컨테이너에 CPU, 메모리, 디스크를 얼마나 줄지 정하는 일도 웹 화면에서 한다.
