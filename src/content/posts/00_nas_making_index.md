## 1. 이 시리즈에서 만들 것

이번 시리즈에서는 집에 있는 컴퓨터 한 대로 파일 저장소를 직접 만든다.

최종 목표는 다음 구조를 직접 만들고 이해하는 것이다.

```text
home nas/
└── wtrmax/ (하드웨어)
    └── Proxmox/ (호스트)
        ├── ZFS 저장 풀/ (호스트 저장소)
        ├── Nextcloud/ (LXC)
        ├── Samba/ (LXC)
        └── 프록시/ (LXC)
```


만드는 순서는 다음과 같다.

```text
소개 → 저장소 → Nextcloud → 외부 접속 → 윈도우 연결
```

### 2-1. wtrmax, 집 서버 하드웨어 간단 소개

가상화로 여러 서비스를 한 기계에 나눠 돌리는 방법을 알아본다.

### 2-3. Nextcloud·Samba·프록시, NAS를 이루는 소프트웨어 3가지
각 소프트웨어가 맡은 역할이 무엇인지 알아본다.

## 3. 저장소 만들기

여러 디스크를 하나의 풀로 묶고, 작은 파일은 NVMe로 보내는 설정을 알아본다.

### 3-2. 사용자 폴더와 바인드 마운트
사용자별 폴더를 만들고, Nextcloud가 볼 수 있게 연결하는 방법을 알아본다.
